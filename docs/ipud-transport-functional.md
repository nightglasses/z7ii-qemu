FIFO depth32, packet staging/commit, read-pop/ACK-only, zero reset, pending meanings and mask/W1C polarity are virtual conventions constrained by original consumers. Configuration completion is not inferred from a readback value. This profile requires the observed fullword configuration before CMD2; it does not recover physical configuration fields. RX0/2 pending meanings below are unrelated to guest software event flags, which only original ISR/worker code may change.

The independent nominal clock is **48MHz**, consuming one committed32-bit word per32 ticks (**666 ns** under the official Clock integer conversion). Uncommitted words do not tick. Disconnected output consumes into a named sink and generates no reply. TXspace pendingbit2 latches only when real consumption crosses from occupancy>29 to≤29; empty reset/configuration and reads do not latch or continuously reassert it. Further consumption without another threshold crossing cannot generate another space event. Pending remains independently masked/acknowledged. Official board wiring connects the device's single output to mature **GIC101**, matching original registration/enable. The model never removes entries from software queues or invokes their callbacks/events; the original SMP worker must make progress itself.

An optional official `peer` chardev property supplies an independently defined **virtual external framing API**: each12-byte little-endian frame contains exactly three32-bit words. This is not a recovered physical wire or an automatic peer. Complete packets reserve three RX slots atomically; partial frames remain outside the FIFO/pending until complete, and reception backpressure stops accepting input when three slots are unavailable. Closed endpoints discard a truncated partial frame without manufacturing a word. A complete explicit frame latches RX pendingbit0. TX emits actual retained little-endian words to an explicitly connected backend; partial/blocked backend writes keep the head word queued and retry on nominal deadlines, preserving output progress. Default original runs do not configure a chardev and have empty RX; no message, tag, reply, peer identity or remote completion is injected. These framing/endpoint semantics are named functional inputs, not source-proven physical behavior.

Controller reset cancels timers and discards staged/committed TX, queued RX, partial frame/output progress, configuration, mask and pending. It notifies the official backend that capacity is available; any later provider data is an explicit external input. Already emitted external bytes cannot be retracted. Reconfiguration accepts only the observed words and leaves in-flight transport intact. Shutdown's guest worker-stop API is not silently treated as a hardware reset.
