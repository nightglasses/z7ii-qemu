# Peripheral event router functional profile

The [runtime audit](runtime.md) establishes the five paired controls at00..24
and the request/IRQ consumers. The current [finite timing model](timing.md)
implements aligned WRITE32 value1 at28/2C/30 with explicitly inferred resync,
synchronization and auxiliary fence behavior. The MAS virtual input advances
original execution to capture-control PA2006800c; physical TG fidelity is unproved.

The original Z7II callback registrar reads and modifies a mask at 20060034. Its whole family owns finite configuration, three raw pending/ACK domains and guest callback dispatch. The model uses the functional name `peripheral-event-router`; this does not identify a physical chip or SoC block. It lives under `hw/nikon/devices/` and is instantiated by the Z7II machine. No address-number type or compatibility alias is added.

Source contract `114f3d1e41410a176ef25bef5e9be5e5e779a39c` in TOOL's `qemu-peripheral-event-router-contract.md` preserves 1728 bytes/696 continuous diagnostic instructions, 13 saved function metadata records/276 instructions, two lane tables and the eleven callback masks. The actual registrar's separately selected source is 13 BB/100 bytes/37 instructions with zero direct frontier. Those diagnostic and saved-source scopes remain different. Original package callbacks, mutexes, registry fields and event flags remain guest RAM and guest code.

The sparse aligned32 aperture is [20060000,20060330). The set/clear pairs00/04,08/0C,10/14,18/1C,20/24 use generated masks3F,7FFF,1,1,7FF. Each pair shares state, read through the set port; clear-port reads are unsupported. Mask/config words34/40/4C retain full32 because the original setters have unclamped word inputs. Configuration at70..9C,A0/A8/AC/B0,314 and the six lanes' C8/CC/D0/D4/D8/DC/EC words is retained full32. The six E8 lane words,B4..C4 and328/32C are generated bytes. A4 accepts changes to low five bits while preserving all other prior bits. Low-level index APIs have no proven dynamic bound; ownership of finite physical words is not a claim that every out-of-range packet can be detected. A4 remains retained configuration;70 low two bits now control the functional force level as specified in timing.md.

IRQ86 dispatches raw38 low11 to eleven guest callbacks. IRQ87 dispatches raw44 to two callbacks and IRQ88 dispatches raw50 to one. The machine connects these three mature SysBus IRQ outputs to GIC86/87/88. IRQ89..93 have no established producer in this family and are not added. `external-pending` qdev inputs are an explicit virtual fixture interface: pins 0..10 latch raw38 bits0..10, pins11..42 latch raw44 bits0..31 and pins43..74 latch raw50 bits0..31 on rising edges. The original run leaves every provider disconnected.

Cold configuration/pending zero, rising-edge latches and same-word W1C are named functional assumptions. Mask1 enables delivery;34's software callback association is evidenced, while40/4C filtering remains a virtual convention. Mask changes retain pending; reads do not ACK or generate events. Reset/unrealize cancel boundary and fence timers and clear configuration/pending while preserving actual provider levels. The original guest executes handlers and callbacks. The finite timers produce only documented pending causes, without DMA, pixel frames, host callbacks or direct flag/task writes.

Unknown commands/reads at28/2C/30, holes, invalid fields and unsupported widths fail before modifying prior state. B0's nonzero readback is its retained written value, not an independent ready source. Original callback registrar input and callback pointers are never host-filled.

Current native evidence is23 SLA plus25 memory cases, including request, timing, cancellation and negative boundaries; see timing.md. Earlier fixture receipts remain immutable. Whole boot and menu are unverified.
