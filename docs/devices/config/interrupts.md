# Configuration transactions and interrupts

The complete original SLA functions in provider `43d1909`, `sla-whole-source-5/sla.S`, extend the earlier complete snapshot producer. `1005A354` (original O238420, bytes `2de9fc5f`, Thumb) writes the first enable/pending registers and calls `1005A2EE` eight times. Each call programs three ports, four rows per port and two words per row: 192 distinct slot words overall. It closes TAEN before writing the configuration request. Therefore requiring nineteen newly written configuration words, 512 newly written slots, or an open TAEN at submission was an invalid restriction to one earlier producer shape. Unwritten draft words retain their previous state.

The [manufacturer driver](https://github.com/killsmm/m10v_mono/blob/cebff0686425b739bf63e87c911591ab30b03c1a/ca7_rtos/target/cpu_tkernel/basefw/MILB_API/Project/ImageMacro/src/im_mxic.c) separates table access from submission and exposes selective configuration. Its [header](https://github.com/killsmm/m10v_mono/blob/cebff0686425b739bf63e87c911591ab30b03c1a/ca7_rtos/target/cpu_tkernel/basefw/MILB_API/MILB_Header/include/Image/_jdsmxic.h) defines four port selection bits per arbiter. The functional model applies selected sixteen-word table portions and corresponding acceptance bytes, retaining unselected active state. Nikon-specific group words retain the existing atomic snapshot semantics; no physical master assignment is claimed.

All addresses below are functional board PA bindings, with relative offsets decoded by the devices. The first configuration unit has TMIE `2001000C` mask `1F`, pending/W1C `20010010` mask `1F`, diagnostics `20010018/1C/28/2C`, diagnostic clear `20010040=1`, and four detection status/address pairs `20011420/24 + 28*i`. Register fields have zero functional reset. A genuine `20010034=1` request publishes selected configuration after the declared 10us virtual timer, sets pending bit0, and exposes busy/idle through `20010038` bit0. Enabling a latched cause changes IRQ level; W1C acknowledgement removes only written causes. Reads and configuration writes cannot manufacture completion. Diagnostic state has no error producer in this profile; enabling error/monitor causes produces no events.

`1005A5E2` (O239074, `2de9f041`, Thumb) programs the second unit. MXIC-relative `+808/+80C` provide enable and W1C pending masks `7`; `+810/814/820/824` are diagnostic pairs, `+834=1` clears diagnostics. `+830` keeps selector bits `4,5,8,9,12,13,16,17`, with bit0 produced by idle state. Packed acceptance words `+840/+844` use mask `1F1F1F1F`; `+838` selects draft/active readback. A valid `+82C=1` starts its independent 10us publication timer and completion cause bit0. This transaction does not fabricate a bus-error cause or replace the existing region latch/real RAM endpoint semantics.

`1005A842` (O239682, `2de9f84f`, Thumb) reads all eight table banks at `24074000` under TAEN and TRVSW, so the table window supports gated word reads. `1005A12E/1005A17E` select active region views. The machine connects config named output `view[0]` to MXIC named input `view[0]` for the first unit; the second uses `+838` internally. Region snapshots consequently return actual retained active region words.

The complete live parameter producers `1005AABE` (O240318), `1005ACB2` (O240818), and `1005AD94` (O241044) establish two 63-row pairs at CONFIG-relative `2400/2600`, and two 32-row pairs at `5400/5600`, stride8. Word0 keeps mode bits1:0 and period bits27:18; the thirteen earlier period interfaces retain their established bits27:16. Word1 supports the independent RMW fields bits4:0, 11:8 and 21:16, mask `003F0F1F`. TLVL first-word fields extend to four ports per group at `2000/2100 + port*40 + level*C`, with three levels each. Only the earlier two ports expose the other two TLVL words; the new ports expose their source-proved low four-bit first-word interface. All unrelated holes, widths and reserved fields still fail.

The source registration `10059F0A` binds object110 at COPY1 `C10064AC` (original O842980), callback pointer `10059DD1`, and IRQ128. Handler `10059DD0` (O237008, `2de9f047`, Thumb) reads and W1C-acknowledges both finite pending groups. The machine connects MXIC sysbus output0 to config named input `region[0]`; config output0 ORs that genuine level with its own enabled pending state and connects to IRQ128 (GIC SPI index96). This is signal wiring, with no global AddressSpace or DMA engine requirement. Object14F/IRQ118 uses the separate `201A0300` family and is outside this model.

Provider rows preserve actual owners, original O/VA/bytes and Thumb mode, `blocked_reason:null`, but `source_accepted:false`. This document qualifies the recovered command grammar and functional board implementation; it does not assert executable SLA admission, a runtime visit, silicon identity, measured timing or observed reset state. Executable admission remains the sole source collector's responsibility. The three new native cases exercise the sparse/selected transaction, late enable/W1C/reset, second-unit causal publication, and every live parameter pair. Builds and test receipts are supplied by the unique builder; none are claimed here.
