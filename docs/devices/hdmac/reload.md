# HDMAC descriptor reload

Later continuation: the [Audio observation profile](../audio/monitor.md)
crosses the54/58 getter recorded below. The first rejection at that checkpoint is
graphics submission PA201810e0=1 with transfer-stream-truncated. This
document retains its reload-only receipts and scope. Later graphics and RAM

The normal GUI continuation programs three reload flags in the audio input
descriptors. The complete eight-combination family is now supported, across
byte/halfword/word widths and fixed/incrementing endpoints. Original firmware
crosses the old CB rejection and reaches the microphone initializer's return
sequence. Its next first error is an Audio read, not a DMA completion.

## Evidence and interpretation

Code addresses are C1.70 MAS VAs; register addresses below are board PAs.
Original `102dc41e` copies request bytes10/11/12 to CB bits23/22/21.
The matching [Socionext register header](https://github.com/killsmm/m10v_mono/blob/cebff0686425b739bf63e87c911591ab30b03c1a/ca7_rtos/target/cpu_tkernel/basefw/MILB_API/MILB_Header/include/Peri/_hdmac.h#L30-L65)
identifies these as RC/RS/RD. They are not protection fields: SP/DP are bits15:8.

| CB bit | Meaning | Normal completion |
|---|---|---|
| 23 RC | Reload count | Restore initially programmed BC and TC |
| 22 RS | Reload source | Restore initial SA |
| 21 RD | Reload destination | Restore initial DA |

The manufacturer-authored [MB86R03 manual](https://www.farnell.com/datasheets/877079.pdf#page=187),
edition1.2, printed11-13, specifies restoration after completion. Printed11-9
separately specifies that completion clears EB and requires another enable.
This is a related-IP reference, not identification of Nikon silicon or measured
Nikon readback. The finite model adopts these semantics with a snapshot at
accepted start. PB/DH/DREQ hold and resume the same snapshot; successful final
bus completion restores only selected fields before publishing SS5/CI.

Cancellation, reset and bus errors do not reload or produce a successful
completion. Partial accepted writes remain visible. That error/cancel policy
and existing non-reload end-counter-zero readback are functional conventions;
physical partial-counter behavior remains unverified. Generation checks after
real bus accesses prevent reentrant cancellation from finishing an old request.
No cyclic repeat or new demand line is generated by reload.

The original audio builder `1036de50` sets all three flags, MS2/TW2 and BC0,
TC=`bytes/4-1`. `1036e016` fixes the input source and selects IS5;
`1036e06a` selects IS6. `102de970` programs these two buffers from the
microphone initializer `102de9bc`. The original HDMAC start `102dc4ec` sets
CI/EI, clears ST for peripheral requests and sets EB. Original ISR
`102dc302` saves SS/BC/TC, clears SS/CI/EI and calls the installed guest
callback. The device never calls guest callbacks itself.

## Native validation

The old model fails the new reload matrix on its first RD configuration:
CB readback00180000 differs from requested00380000. The changed model passes
one applicable batch:10 `nikon_dma`,4 `nikon_hdmac`,4 `nikon_audio` and3
`nikon_memory_unit` cases. New matrix coverage is all8 reload combinations ×
3 widths ×4 fixed-address combinations, with real destination bytes, separate
field readbacks, IRQ acknowledgement and no automatic repeat. Lifecycle and
self-MMIO cases cover software rearm, fresh snapshot, hold/resume, cancel,
reset and genuine reentrant PB/cancel writes.

A subsequently added private-root/DREQ case passes in the focused5-case
`nikon_hdmac` run. It verifies held input, first-beat progress, restoration only
after the last beat, a still-high request without restart, and actual second-beat
SS3/SS4 failures without restoration. Added negative guards pass in a focused
3-case reload run: reserved/protection/TT/TW/MS and active descriptor edits
remain rejected with preserved state. These are synthetic tests, not original
sample production. Receipts: `work/runs/hdmacflags-20261023/native-red.log`,
`native-green.log`, `native-boundaries.log`, `native-guards.log`.
