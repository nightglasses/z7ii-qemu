# Published execution evidence

The handbook embeds the register fields, call chains, observations, assumptions
and validation limits needed to read each contract. The attachments below are
tracked in Git and shipped with the site; they do not depend on a developer's
local directories. They are existing receipts, not fresh executions.

## Archive scope

Execution JSON retains measured values, counters and error boundaries. Long
binary snapshots are explicitly omitted; no factory firmware or disassembly is
redistributed. Native text files contain the original verdict/assertion lines,
with machine-specific absolute paths removed. An expected red fixture remains
a red fixture; diagnostic input and normal input results remain distinct.

## Historical records

Some early raw captures are no longer available. Their observations and limits
remain embedded in the historical pages, with fixed source/commit references
where retained. Run identifiers on those pages are provenance labels, not
promises of a downloadable log. The page's Evidence section identifies which
attachments actually exist. Unarchived results must not be presented as freshly
verified or as complete boot evidence. No missing capture has been fabricated.

Operational build and launch paths are instructions for creating local outputs;
they are not citations to unpublished evidence.
